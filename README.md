# Amazon-Sales-Analytics-Dashboard-Excel
Interactive Amazon Sales Dashboard built in Microsoft Excel  to analyze sales, orders, customers, products, payment methods, order status, and monthly performance using PivotTables, PivotCharts, slicers, and KPI cards.

## Project Overview
This project is an interactive Amazon Sales Dashboard created using Microsoft Excel.
The dashboard provides a visual overview of sales performance, orders, customers, products, payment methods and order status.
The project was created as a practical data analytics / MIS reporting project.

## Key Business Insights

Some important observations from the dashboard include:
  
  1.   Total revenue was approximately ₹3.94 crore across 39,966 orders.
  2.   Average Order Value (AOV) was ₹986.
  3.   75% of orders were successfully delivered.
  4.   15% of orders were in the shipped status, while 4% were pending.
  5.   Returned and cancelled orders accounted for approximately 3% each.
  6.    The United States generated the highest sales among the countries analyzed.
  7.    Electronics was the highest-performing product category.
  8.    Credit Card was the most-used payment method, accounting for 35% of transactions.
  9.    Dress Shirt ranked first among the Top 5 products displayed.
  10.   Monthly sales varied throughout the year, with particularly strong performance in May and December 2024.
